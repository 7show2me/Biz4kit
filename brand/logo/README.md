Biz4Kit logo files. The mark is a 4 and a B in Playfair Display Black (weight 900, lining figure), upright and the same height, joined by one bold dash through their upper third. The lockup adds "Biz4Kit" in Playfair Display Black beside it. Every letter is outlined, so no font is needed to display the files. Every file is an SVG shown with `<img>`, so the ink is fixed per file. Files marked "tile" sit on their own dark rounded background with a visible border, so they show on any page.
